# Contributing

Thank you for taking the time to improve this portfolio or its project documentation.

## Ways to contribute
- Report an issue or documentation error.
- Suggest a workflow improvement.
- Share a reproducible bug report.
- Propose a project idea relevant to AI automation.

## Before submitting
1. Search existing issues to avoid duplicates.
2. Explain the problem and expected behavior.
3. Include sanitized examples, screenshots, or workflow steps when useful.
4. Remove API keys, tokens, email addresses, customer data, and other secrets.

## Pull requests
- Keep changes focused and clearly described.
- Update relevant documentation.
- Do not commit credentials, private exports, or personal customer information.
- Test workflow changes where possible and describe the test performed.

All contributions should be respectful, constructive, and focused on making the documentation more useful.
