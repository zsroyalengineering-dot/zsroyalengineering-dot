# Assets

Store portfolio images and diagrams in this folder.

Suggested files:
- `profile-banner.png` — optional GitHub profile banner
- `workflow-*.png` — sanitized workflow screenshots
- `architecture-*.png` — project architecture diagrams

Use clear filenames and add descriptive alt text when embedding images in Markdown. Only upload images you own or have permission to use. Remove credentials, private URLs, customer data, and personal information from screenshots before publishing.
